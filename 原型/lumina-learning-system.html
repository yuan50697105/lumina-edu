01 · Background

§1 背景与目标

1.1 · 业务背景

Lumina 墨光已完成 M1-M3 阶段：课程 / 作业 / 成绩 / AI 对话 / 直播 / 协作 / 通知 / 题库考试 等核心教学链路已稳定落地。但当前平台主要服务「被组织的教学」（教师开课 → 学生选课 → 按时上课），缺少面向学生主动性的自学与激励体系。

高校教学反馈显示：学生课外自学缺乏引导、学习动力难以持续、优秀学习者无法获得认可。本需求通过「闯关式学习路径 + 游戏化激励」补齐这块拼图，让 Lumina 从"教学工具"升级为"学习伴侣"。

1.2 · 核心目标

目标维度描述量化指标
🎯 提升自学参与率 学生愿意在课程之外主动学习拓展内容 DAU 中 ≥30% 进入学习路径
🔥 增强学习粘性 通过打卡、连续天数、排行榜维持习惯 周活跃天数 ≥ 4 天的用户占比 ≥ 25%
🏆 构建成就体系 让优秀可见：徽章、等级、排行榜形成正反馈 每学期人均获得 ≥ 3 枚徽章
📚 沉淀内容资产 教师把零散资料串成结构化路径，可复用 每学期新增 ≥ 20 条学习路径
📘 定位
补充性模块，不阻塞主流程：学习路径与正式课程并行，闯关积分独立于课程成绩（GPA），但可通过徽章/排行激励反哺课程参与。

03 · Modules

§3 功能模块设计

本需求拆为 3 个内聚模块，分别对应「自学引导 / 游戏激励 / 成就沉淀」三大目标。

🗺️
A · 自主学习路径 Self-Learning Paths

教师把零散资料（文章/视频/小测）串成一条有序的"闯关地图"，学生按顺序推进。

A.1 · 核心概念

概念说明示例
学习路径 Path 一个主题的完整自学路线，含难度/分类/封面/总 XP 《Python 入门闯关》· beginner · 200 XP
关卡 Stage 路径中的一步：承载一种资源类型 + 通关奖励 第 3 关 · 视频 10 min · 20 XP
进度 Progress 学生在某关的状态：locked / unlocked / in_progress / completed 第 2 关已完成 · 第 3 关进行中

A.2 · 资源类型

类型承载形式通关条件
article富文本内容内嵌点"我读完了"即通过
video外链 / 内嵌播放器观看 ≥ 80% 时长（前端上报）
quiz多道客观题答题正确率 ≥ 60%
challenge综合挑战（多题型）得分 ≥ 阈值 + 时间限制

A.3 · 解锁规则

🔓 默认线性解锁
第 N 关完成 → 第 N+1 关自动解锁。支持 unlock_condition JSON 扩展：
  • 前置关卡：{"requires_stages": ["stage_id_1", "stage_id_2"]}
  • 最低等级：{"min_level": 5}
  • 特定徽章：{"requires_badge": "badge_id"}

A.4 · 学生主流程

1
浏览路径广场
按分类/难度/标签筛选，看封面/总 XP/已参与人数
2
进入路径地图
查看全路径关卡地图（节点连线图），已完成的亮起，当前关高亮，未解锁置灰
3
推进当前关
阅读/观看 → 答题 → 系统判分 → 发放 XP → 解锁下一关
4
路径完成
全关通过 → 弹出"路径完成"动画 + 总 XP 奖励 + 解锁"路径征服者"徽章
🎮
B · 游戏化激励 Gamification Engine

通过 XP / 等级 / 连续打卡 / 每日挑战 形成持续的学习正反馈。

B.1 · 经验值（XP）体系

动作XP 奖励说明
每日打卡10 + streak×2（上限 50）首次进入 APP 触发，连续越多奖励越高
通关关卡关卡设定值（默认 10~50）测验关按得分比例折算
答对每日挑战20（默认）答错不扣分但无奖励
获得徽章徽章配置值（0~200）一次性奖励
完成整条路径路径 total_xp额外叠加"路径完成"奖励徽章

B.2 · 等级称号

等级区间称号所需 XP视觉标识
Lv 1~4初心者0~599灰阶徽章框
Lv 5~9进取600~2399青铜框
Lv 10~19好学2400~6199白银框
Lv 20~29学者6200~13999黄金框
Lv 30~49学霸14000~39999铂金框
Lv 50+学神40000+钻石框 + 光效
⚠ 等级公式
Lv(N→N+1) = 100 + 200×(N-1) XP。Lv1→2 需 100，Lv2→3 需 300，Lv3→4 需 500…封顶 Lv 100。确保前期升级快（正反馈）、后期升级难（持续挑战）。

B.3 · 每日挑战

  • 发布：教师/管理员提前发布，设定 active_date 和 expires_at
  • 题型：选择题（quiz）/ 阅读打卡（reading）/ 练习题（exercise）
  • 生命周期：每日 00:00 刷新，24 小时窗口；过期进入"历史题库"
  • 幂等：每人每日每挑战仅一次作答机会，已答完返回原结果
  • 解析：答完立即展示正确答案 + 解析（explanation 字段）

B.4 · 连续打卡（Streak）

1
每日首次学习行为
任意通关/答题/打卡触发 → 更新 last_active_date
2
连续判定
若 last_active_date == 昨天 → streak += 1；否则 → streak = 1
3
记录最长连续
longest_streak = max(longest_streak, current_streak)
4
断签保护（V2 考虑）
未来可引入"补签卡"道具（消费 XP 购买）
🏆
C · 成就沉淀 Badges & Leaderboard

徽章承载"里程碑"时刻，排行榜提供"可比较"维度，二者叠加形成持续成就反馈。

C.1 · 徽章分类

类别触发条件示例
XP 阈值 xp_threshold · total_xp ≥ N 「初露锋芒」100 XP · 「学海无涯」10000 XP
连续打卡 streak · current_streak ≥ N 「七日成习」7 天 · 「月度坚持」30 天
路径完成 path_complete · 完成 N 条路径 「单线突破」1 条 · 「博学者」10 条
挑战大师 challenge_master · 答对 N 次挑战 「答题新秀」10 次 · 「常胜将军」100 次
首次行为 first_login · 注册后首次进入 「墨光初识」· 欢迎徽章

C.2 · 徽章自动授予流程

1
XP/Streak/完成行为发生后
在发放 XP 后统一调用 _check_badges()
2
遍历所有未获得的徽章
按 condition_type 计算是否满足
3
满足条件 → 写入 user_badges
同时发放徽章配置的 XP 奖励（可叠加）
4
返回前端「新获得徽章」列表
前端弹窗展示，支持一键分享

C.3 · 排行榜

维度算法更新频率
周榜本周有 XP 流水的用户按 total_xp 排序实时，周一 00:00 重置统计窗口
月榜本月有 XP 流水的用户按 total_xp 排序实时，每月 1 日重置统计窗口
总榜所有用户按 total_xp 排序实时
🛡️ 防刷策略
排行榜仅统计有有效行为的 XP（每日挑战 / 路径通关 / 打卡），且每类行为每日有上限（如打卡 1 次、每日挑战 1 次）。未来可引入"周 XP 获取上限"（如 2000 XP/周）防止恶意刷分。

05 · API Design

§5 接口设计（~20 端点）

新增模块 /api/v1/learning/*，统一前缀 /learning，按子资源分组。所有端点需 Authorization: Bearer {token}。

5.1 · 学习路径

GET/learning/paths?category=&difficulty=&status=&offset=&limit=
路径列表（学生默认只看 published，教师/admin 可看全部）
GET/learning/paths/{path_id}
路径详情（含 stage_count / enrolled_count / my_progress）
POST/learning/paths
创建路径（teacher/admin）
PUT/learning/paths/{path_id}
更新路径（owner 或 admin）
DELETE/learning/paths/{path_id}
删除路径（级联删关卡/进度）

5.2 · 关卡

GET/learning/paths/{path_id}/stages
关卡列表（含我的进度状态 locked/unlocked/in_progress/completed）
POST/learning/paths/{path_id}/stages
创建关卡（自动重算路径 total_xp）
PUT/learning/stages/{stage_id}
更新关卡
DELETE/learning/stages/{stage_id}
删除关卡
POST/learning/stages/{stage_id}/complete
通关关卡（校验前置关 + 测验判分 + 发放 XP + 检查徽章）

5.3 · 我的进度

GET/learning/my/progress
我的学习进度汇总（按路径聚合，含百分比）

5.4 · 每日挑战

GET/learning/challenges/today
今日挑战列表（隐藏答案字段）
GET/learning/challenges?offset=&limit=
历史挑战列表
POST/learning/challenges
创建每日挑战（teacher/admin）
POST/learning/challenges/{id}/attempt
提交挑战答案（判题 + 发 XP + 检查徽章）

5.5 · 积分 / 徽章 / 排行榜 / 打卡

GET/learning/my/points
我的积分/等级/连续天数/排名/徽章数
GET/learning/badges
徽章列表（含我是否已获得）
POST/learning/badges
