01 · 概述与架构 Overview

Architecture

1.1 存储架构

存储引擎用途版本部署
MySQL 9.7数据主库 · 全部业务/AI 数据9.7单库 · 单体直连

说明：单体架构仅依赖 MySQL 9.7 单库，业务 / AI / 日志数据统一落 MySQL（InnoDB · utf8mb4）；表由 Base.metadata.create_all 自动创建（development 模式），生产初始化脚本见 部署/config/mysql/init.sql。缓存 / 消息队列 / 对象存储等中间件已从单体移除。单体包含 9 个业务模块：user / course / assignment / grade / ai_gateway / ai_chat / ai_grade / analytics / logs。

08 · 分区策略 Partitioning

MySQL 原生分区

8.1 分区策略

说明：采用 MySQL 原生分区（RANGE / LIST / HASH / KEY），所有分区表仍落在同一实例，分区对上层应用透明，无需任何分片中间件。注意：MySQL 要求分区键必须包含在表的所有唯一键中。

数据表分区键策略分区数预计规模
coursessemesterLIST 分区（学期）~20 分区500 门/学期
submissionssubmitted_atRANGE 分区（时间）滚动 12 月10 万+/学期
api_logscreated_atRANGE 分区 · 冷热分离热 3 月 + 冷归档500 MB/日
ai_conversationscreated_atRANGE 分区（时间）滚动 12 月50 万+会话
live_messagescreated_atRANGE 分区（时间）滚动 12 月规划中

8.2 分区示例

-- courses 按学期分区
CREATE TABLE courses (
  ...

CREATE TABLE courses_2026_1 PARTITION OF courses

9.3 查询优化示例

-- 查询学生本学期课程（利用索引）
SELECT c.* FROM courses c
JOIN enrollments e ON c.id = e.course_id
WHERE e.user_id = $1
  AND c.semester = '2026-1'
  AND e.status = 'active';

-- AI 对话历史（利用索引）
SELECT * FROM ai_conversations
WHERE user_id = $1
ORDER BY updated_at DESC
LIMIT 20;

-- 课程作业统计（利用索引）
SELECT a.id, a.title,
  COUNT(s.id) AS submission_count
FROM assignments a
LEFT JOIN submissions s ON a.id = s.assignment_id
WHERE a.course_id = $1
GROUP BY a.id;

10.3 迁移示例

-- 迁移示例（Alembic 规划中）
ALTER TABLE assignments
  ADD COLUMN ai_grading BOOLEAN DEFAULT false,
  ADD COLUMN rubric JSONB,
  ADD COLUMN ai_model VARCHAR(50);

CREATE TABLE ai_conversations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id),
  title VARCHAR(200),
  model VARCHAR(50),
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE ai_messages (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  conversation_id UUID REFERENCES ai_conversations(id),
  role VARCHAR(20) NOT NULL,
  content TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);
✅ 迁移原则
  • 向后兼容：新字段必须有默认值或允许 NULL
  • 零停机：大表变更使用 pt-online-schema-change 或分批处理
  • 可回滚：每个迁移配套 rollback SQL
  • 幂等：迁移脚本可重复执行不报错
