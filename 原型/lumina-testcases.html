TC-USER-005 自助注册 · 成功与冲突（D-03） P1

前置条件：邮箱 / 学号未占用

测试步骤：

  1. 调用 POST /auth/register，提交 name / email / password / role=student
  2. 检查响应状态码 201，返回令牌（注册即登录）
  3. 查询我的通知应有 1 条「欢迎加入 Lumina 墨光」（notif 写入）
  4. 用相同邮箱再次注册，断言 409 EMAIL_EXISTS
  5. 提交非法角色 / 短密码，断言 422

预期结果：注册成功且自动登录 · 冲突与参数非法被拒绝

自动化：✓ 已覆盖（smoke_notif.py 注册步骤 + test_notif.py 角色校验）

TC-NOTIF-001 消息通知中心 · 未读 / 已读 / 全部已读（D-03） P1

前置条件：存在至少一条未读通知（如注册欢迎 / 批阅完成 / 直播点名）

测试步骤：

  1. 调用 GET /notifications/my/unread-count，未读数 ≥ 1
  2. 调用 GET /notifications/my 获取列表，验证含 type / title / ref_type / is_read
  3. 调用 POST /notifications/my/{id}/read 单条已读，未读数 -1
  4. 调用 POST /notifications/my/read-all，未读归零 · 重复调用幂等
  5. 用他人身份访问该通知，断言 404（越权不可见）

预期结果：仅本人可见 · 已读状态正确 · 越权 404

自动化：✓ 已覆盖（test_notif.py 13 用例 + smoke_notif.py 12 步）

9.2 CI 集成

# .github/workflows/test.yaml
name: Test
on: [push, pull_request]

jobs:
  unit-test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v4
    - name: Run Unit Tests
      run: make test-unit
    - name: Upload Coverage
      run: bash <(curl -s https://codecov.io/bash)

  integration-test:
    needs: unit-test
    runs-on: ubuntu-latest
    services:
      mysql:
        image: mysql:9.7
        env:
          MYSQL_ROOT_PASSWORD: test
          MYSQL_DATABASE: lumina_test
    steps:
    - name: Run Integration Tests
      run: make test-integration

  api-test:
    needs: integration-test
    runs-on: ubuntu-latest
    steps:
    - name: Run API Tests
      run: newman run tests/api/lumina-api.postman_collection.json
