02 · 单体应用部署 Deployment

Docker Compose

2.1 部署架构

ℹ 拓扑
入口：Nginx :80（静态资源 + 反代 /api/*）→ lumina-app :8080（单体 API）→ MySQL :3306（持久化）+ Redis :6379（会话缓存）。
4 服务由 部署/docker-compose.yml 一键编排，全部数据落 MySQL 库 lumina（35 表），无外部依赖。

2.2 单体应用部署（Docker Compose）

# docker-compose.yml
services:
  mysql:
    image: mysql:9.7
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: lumina
      MYSQL_USER: lumina
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
    volumes:
      - mysql_data:/var/lib/mysql
    ports:
      - "3306:3306"

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  lumina-app:
    build: ../服务/lumina-app
    environment:
      DATABASE_URL: mysql+pymysql://lumina:${MYSQL_PASSWORD}@mysql:3306/lumina?charset=utf8mb4
      JWT_SECRET_KEY: ${JWT_SECRET_KEY}
    ports:
      - "8080:8080"
    depends_on:
      - mysql
      - redis

2.3 Nginx 反向代理

# nginx.conf
server {
    listen 80;
    server_name _;

    # 前端静态文件
    root /usr/share/nginx/html;
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理（统一转发至单体应用）
    location /api/ {
        proxy_pass         http://lumina-app:8080;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_read_timeout 300s;  # AI 流式响应
        proxy_buffering    off;   # SSE 不缓冲
    }
}

2.4 启动命令

# 停止服务

03 · CI/CD 流水线 Pipeline

GitHub Actions

3.1 流水线阶段

阶段触发条件耗时产物
① 代码检查PR 提交~2 minLint 报告
② 单元测试PR 提交~5 min覆盖率报告
③ 构建镜像合并 main~3 minDocker 镜像
④ 安全扫描合并 main~2 min漏洞报告
⑤ 部署 Staging合并 main~5 minStaging 环境
⑥ 集成测试Staging 部署后~10 min测试报告
⑦ 人工审批测试通过后—审批记录
⑧ 部署 Production审批通过~10 min生产环境

3.2 GitHub Actions 示例

# .github/workflows/deploy.yaml
name: Deploy
on:
  push:
    branches: [main]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v4

    - name: Unit Tests
      run: |
        cd 服务/lumina-app
        python -m pytest tests -q

    - name: Build Image
      run: |
        docker build -t registry.lumina.edu/lumina-app:latest 服务/lumina-app
        docker push registry.lumina.edu/lumina-app:latest

  deploy:
    needs: build-and-test
    runs-on: ubuntu-latest
    environment: production  # 需要人工审批
    steps:
    - name: Deploy to Server
      run: |
        ssh deploy@host "cd /opt/lumina && docker compose pull && docker compose up -d"

07 · Runbook 手册 Procedures

Standard Operations
P1 · 严重 MySQL 数据恢复

触发条件：MySQL 容器损坏 / 数据卷异常 / 误删数据

影响：全站读写失败

操作步骤：

  1. 确认容器状态：docker-compose ps mysql
  2. 从每日备份恢复：docker-compose exec -T mysql sh -c 'exec mysql -ulumina -p"$MYSQL_PASSWORD" lumina' < backup_YYYYMMDD.sql
  3. 验证表数据：docker-compose exec mysql mysql -ulumina -e "SELECT COUNT(*) FROM users"
  4. 重启应用并检查 /health 恢复
  5. 记录事故报告，确认备份保留周期
P2 · 警告 服务扩容

触发条件：CPU > 80% 持续 5 分钟 或 请求量激增

操作步骤：

  1. 确认扩容目标：docker-compose ps
  2. 手动扩容：docker-compose up -d --scale lumina-app=3
  3. 观察新容器启动：docker-compose ps -a
  4. 确认流量均匀分布
P3 · 信息 版本回滚

触发条件：新版本出现严重 Bug

操作步骤：

  1. 确认上一个稳定版本：git log --oneline -5
  2. 回滚到指定版本：git checkout <commit-hash> -- 服务/lumina-app
  3. 重新部署：docker-compose up -d --build lumina-app
  4. 验证服务恢复
  5. 记录事故报告
