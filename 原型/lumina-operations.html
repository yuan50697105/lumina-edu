2.2 单体应用部署（Docker Compose）

# docker-compose.yml
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: lumina
      POSTGRES_USER: lumina
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
    volumes:
      - pg_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  lumina-app:
    build: ../服务/lumina-app
    environment:
      DATABASE_URL: postgresql://lumina:${POSTGRES_PASSWORD}@postgres:5432/lumina
      JWT_SECRET_KEY: ${JWT_SECRET_KEY}
    ports:
      - "8080:8080"
    depends_on:
      - postgres
      - redis

2.3 Nginx 反向代理

# nginx.conf
server {
    listen 80;
    server_name _;

    # 前端静态文件
    root /usr/share/nginx/html;
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理（统一转发至单体应用）
    location /api/ {
        proxy_pass         http://lumina-app:8080;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_read_timeout 300s;  # AI 流式响应
        proxy_buffering    off;   # SSE 不缓冲
    }
}

03 · CI/CD 流水线 Pipeline

GitHub Actions

3.1 流水线阶段

阶段触发条件耗时产物
① 代码检查PR 提交~2 minLint 报告
② 单元测试PR 提交~5 min覆盖率报告
③ 构建镜像合并 main~3 minDocker 镜像
④ 安全扫描合并 main~2 min漏洞报告
⑤ 部署 Staging合并 main~5 minStaging 环境
⑥ 集成测试Staging 部署后~10 min测试报告
⑦ 人工审批测试通过后—审批记录
⑧ 部署 Production审批通过~10 min生产环境

3.2 GitHub Actions 示例

# .github/workflows/deploy.yaml
name: Deploy
on:
  push:
    branches: [main]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v4

    - name: Lint
      run: make lint

    - name: Unit Tests
      run: make test

    - name: Build Image
      run: |
        docker build -t registry.lumina.edu/${{ github.event.repository.name }}:${{ github.sha }} .
        docker push registry.lumina.edu/${{ github.event.repository.name }}:${{ github.sha }}

  deploy-staging:
    needs: build-and-test
    runs-on: ubuntu-latest
    steps:
    - name: Deploy to Staging
      run: |
        helm upgrade --install ${{ github.event.repository.name }} \
          --namespace lumina-staging \
          --set image.tag=${{ github.sha }}

  deploy-production:
    needs: deploy-staging
    runs-on: ubuntu-latest
    environment: production  # 需要人工审批
    steps:
    - name: Deploy to Production
      run: |
        helm upgrade --install ${{ github.event.repository.name }} \
          --namespace lumina-prod \
          --set image.tag=${{ github.sha }}

07 · Runbook 手册 Procedures

Standard Operations
P1 · 严重 数据库主从切换

触发条件：PostgreSQL 主库不可达

影响：所有写操作失败，读操作降级到从库

操作步骤：

  1. 确认主库状态：kubectl exec postgres-primary -- pg_isready
  2. 触发自动切换：kubectl exec postgres-primary -- patronictl switchover
  3. 验证新主库：kubectl exec postgres-replica-0 -- pg_isready
  4. 检查应用连接恢复
  5. 修复原主库，重新加入集群
P2 · 警告 服务扩容

触发条件：CPU > 80% 持续 5 分钟 或 请求量激增

操作步骤：

  1. 确认扩容目标：docker-compose ps
  2. 手动扩容：docker-compose up -d --scale lumina-app=3
  3. 观察新容器启动：docker-compose ps -a
  4. 确认流量均匀分布
P3 · 信息 版本回滚

触发条件：新版本出现严重 Bug

操作步骤：

  1. 确认上一个稳定版本：git log --oneline -5
  2. 回滚到指定版本：git checkout <commit-hash> -- 服务/lumina-app
  3. 重新部署：docker-compose up -d --build lumina-app
  4. 验证服务恢复
  5. 记录事故报告
