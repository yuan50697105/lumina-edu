交互说明 Interactions

  • 底部 Tab：学习 / 视频 / 成就 / 历史 / 我的 五视图切换，当前 Tab 钴蓝高亮 + 轻震动反馈。
  • 学习：广场筛选 chips 过滤路径 → 点卡片进入竖向时间线地图（✓ 绿 / 🎯 蓝 + 荧光黄脉动 / 🔒 灰）→ 点当前关底部弹出半屏面板 →「开始闯关」。列表↔地图可返回。
  • 视频：搜索 + 分类 chips 实时过滤 → 点卡片进入播放器：播放/暂停（模拟走秒）、进度条点选跳转、倍速 1.0x→2.0x 循环、画质 自动→4K 循环、简介/笔记/章节三页签，时间戳可跳转。
  • 打卡：Hero「打卡」按钮 → 连续天数 +1、XP +10、navigator.vibrate([20,40,20]) 震动反馈，当日重复点击提示。
  • 做笔记：悬浮「做笔记」按钮或键盘 N → 自动暂停 + 底部弹出输入面板 → 保存后按时间戳插入笔记列表。
  • 成就：30 天打卡日历横向滚动（黄=已打卡、连线=连续区间、蓝描边=今日）；徽章墙点击弹出详情弹窗（名称/描述/条件）。
  • 历史：视频记录左滑露出删除按钮 →「删除」移除；路径记录带进度条；挑战记录显示结果 ✅/❌ 与所得 XP。
