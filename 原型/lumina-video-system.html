01 · Overview

§1 产品概览

1.1 · 产品定位

Lumina 墨光已完成 M1-M3 阶段核心教学链路（课程 / 直播 / 作业 / 考试 / 学情分析）。但当前「课堂内容」是消耗型的——直播结束即流失，课后无法系统回看；教师自制视频资料散落在网盘 / 群文件，缺少统一管理与学习行为数据。本需求为平台补齐教学视频管理与录播回放能力，支撑「直播 + 录播」双模式教学，让每一堂课都可沉淀、可检索、可度量。

1.2 · 目标用户

角色核心诉求典型场景
教师 上传 / 管理视频，直播课后一键沉淀录播 翻转课堂预习资料、直播课回放、精品课建设
学生 随时观看、断点续播、做时间戳学习笔记 课后复习回看、补课回看直播、按知识点定位难点
管理员 存储治理、UGC 内容审核、成本监控 审核待发布视频、查看存储占用、配置转码策略

1.3 · 核心价值

价值说明量化指标
📼 直播自动转录播 直播结束自动触发录制→转码→发布，零人工干预沉淀回放 课后 10 分钟内生成可回看草稿
📥 离线学习支持 移动端下载缓存，通勤 / 弱网场景可学习 移动端离线视频打开成功率 ≥ 99%
🔍 知识点切片检索 AI 字幕转写 + 关键帧索引，按知识点直达视频片段 检索命中直达时间点误差 ≤ 5s
📊 学习进度追踪 观看时长 / 完播率 / 笔记沉淀，反哺 D-05 学情分析 课程视频完播率可视化覆盖 100% 已发布视频
📘 与 D-01 直播课堂的关系
  • 直播 → 录播自动沉淀：D-01 直播房间结束后，录制流自动转入本模块转码流水线，生成录播并回关联原房间与课程（videos.source_type='live_record'）
  • 独立视频预上传：非直播场景（微课 / 预习资料）可提前上传发布，不依赖 D-01
  • 播放底座复用：录播分发复用 D-01 已有的 HLS 播放链路（含 /media 同源反代），避免第二套播放器体系

02 · Features

§2 功能模块（A~E）

本需求拆为 5 个内聚模块，分别对应「资源管理 / 录播沉淀 / 播放交互 / 智能检索 / 数据度量」五条能力主线。

🎬
A · 视频资源管理 Video Management（教师端）

教师把视频作为一等教学资源纳入课程：上传、组织、编辑、送审全流程自助。

A.1 · 上传规格

项约定
容器/编码mp4 / webm / avi（源文件统一转码为 H.264 + AAC）
分片上传默认 8MB/片，并行 ≤ 4 片；服务端按 upload_id 合并
断点续传暂停/网络中断后凭 upload_id + 已传分片清单续传；MD5 校验完整性
大小上限单文件 4 GB（超限返回 413，可配置）
数量限制单课程默认 200 个视频 / 200 GB 配额，admin 可调整

A.2 · 元信息

  • 必填：标题、所属课程（course_id）
  • 可选：简介、封面（缺省自动抽帧第 60s）、标签数组、章节关联（chapter_id）
  • 元信息随创建请求提交，转码完成后状态方可流转为可发布

A.3 · 列表 / 搜索 / 筛选

  • 维度：按课程 / 章节 / 标签 / 状态 / 时长区间 / 上传时间排序
  • 关键词：标题 + 简介模糊匹配；学生视角仅见已发布且自己已选课程的视频

A.4 · 编辑与删除

  • 修改元信息即时生效；替换源文件重新走转码流水线（旧文件保留 7 天可回滚）
  • 软删除：状态置 archived，30 天内可恢复，到期物理清理存储

A.5 · 视频审核

1
上传完成 → 转码
状态 draft → processing，多码率产物就绪后进入待审核
2
管理员审核 UGC 内容
通过 / 驳回（驳回必填原因，通知上传者）；审核策略可按课程开关
3
发布可见
状态 published，学生端按权限可见；支持下架回 draft
📼
B · 录播回放 Recording Replay（与 D-01 联动）

直播即资产：课堂结束自动沉淀为录播，教师自助剪辑与定时发布。

B.1 · 直播自动录制

1
直播结束事件
D-01 房间 status→ended，触发录制归档 webhook（携带 room_id / course_id / 录制源地址）
2
自动转码
录制文件进入模块 A 同一转码流水线（多码率 + 封面 + 关键帧）
3
生成录播草稿
videos.source_type='live_record'，默认标题「{课程}·{日期} 直播回放」，关联原房间
4
教师确认发布
可先剪辑再发布；发布后在原直播房间入口显示「回看」

B.2 · 录播剪辑（教师自助）

  • 裁剪：设置入点/出点去掉片头等待、下课尾段；预览确认后异步生成新文件
  • 静音段切除：基于音量检测列出静音区间，一键剔除（如网络卡顿空白）
  • 非破坏式：源文件保留（is_original=1），剪辑产物为新版本，可回退

B.3 · 发布控制

  • 手动发布 / 下架；定时发布（publish_at，到点自动上架，配合教学日历）
  • 下架不删除数据，观看记录保留，学生端入口隐藏

B.4 · 观看权限

权限模式可见范围说明
course（默认）已选该课程的学生 + 授课教师 + 管理员选课关系实时校验
public全站登录用户精品公开课场景，需强制审核
password输入访问密码者密码为 4-8 位，分享链接带 ?v= 校验
▶️
C · 视频播放器 Player（学生端）

面向学习场景优化的 HTML5 播放器：流畅、可续播、可批注。

C.1 · 播放能力

  • 自适应码率：HLS 多码率阶梯（4K/1080p/720p/360p）按网络自动切换，支持手动锁画质
  • 倍速：0.5x ~ 2x（步进 0.25），记忆用户偏好
  • 断点续播：进度每 15s 服务端上报（progress_seconds），换设备可续
  • 历史列表：我的最近观看（跨课程聚合），观看时长统计入口

C.2 · 视频笔记

  • 暂停时可插入时间戳笔记（文字），列表按时间轴排列，点击笔记 seek 到对应秒
  • 截图标记：一键截取当前帧存入笔记（screenshot_url），板书/PPT 场景刚需
  • 笔记私有可见（本人）；后续版本可选共享给同课同学

C.3 · 弹幕 / 评论

  • 按视频开关（教师端配置，默认关）；评论与时间轴关联，形成「共学」氛围
  • 复用 D-01 直播弹幕的敏感词过滤与举报链路

C.4 · 字幕支持

  • SRT/VTT 上传：教师/管理员手动挂字幕
  • AI 自动字幕：语音转写（讯飞 / 通义听悟），转码后异步生成，教师可校对修正
  • 多语言：一视频多轨（zh/en/…），播放器字幕轨切换
🔍
D · 知识点与检索 Knowledge & Search

让 90 分钟的回放不再「拖进度条碰运气」：切片、索引、直达。

D.1 · 知识点切片

  • 教师按章节/知识点为视频打标签段（时间点区间 + 知识点名），学生端「目录式」跳转
  • 与课程章节树（chapters）对齐，直播转录播可继承课堂「答题/点名」时间标记

D.2 · 关键帧索引（AI）

  • 转码流水线并行提取关键帧：PPT 切换点（画面突变检测）、板书重点（黑屏/书写区域变化）
  • 关键帧生成缩略图时间轴，悬停预览定位

D.3 · 全文检索

1
语音转文字
字幕转写产物（video_transcripts，含每句时间戳）入库
2
建立检索索引
MySQL 全文索引起步（ngram 中文分词）；数据量增长后评估 ES
3
搜索命中时间点
返回视频 + 命中句 + 时间戳片段高亮，点击进入播放并 seek

D.4 · 学习路径推荐

  • 课程内推荐：未看视频 + 章节进度驱动（「下一章预习」）
  • 与 D-06 学习路径协同：视频可作为路径关卡资源（resource_type='video'）挂载
🤖 AI 能力边界
关键帧提取与语音转写为离线流水线任务（不产生推理网关实时调用费用）；推荐 v1 采用规则策略（进度 + 选课关系），LLM 语义推荐列为 V2 评估项，避免首期引入 ai_gateway 配额风险。
📊
E · 数据分析 Analytics

观看行为沉淀为教学度量：教师看学情，管理员看成本。

报表指标视角
视频观看统计 播放量 · 完播率（progress ≥ 90%）· 平均观看时长 · 观看高峰时段（小时分布） 教师 管理员
学生观看报告 个人：累计时长/完播数/笔记数；班级：覆盖率、未看名单（督学清单） 教师
热门视频排行 课程内 / 全站 Top N（按播放量、完播率双口径） 教师 管理员
存储占用统计 总容量 / 课程分布 / TOP10 大文件 / 配额告警（≥80% 提醒） 管理员
  • 数据口径以 video_views 为准，聚合任务每日凌晨增量汇总（复用 analytics 模块定时框架）
  • 支持 CSV 导出；学生观看报告可回流 D-05 学情分析作为「课外学习投入」信号

03 · User Stories

§3 用户故事与验收标准
ID角色作为…我希望…验收标准（AC）优先级
US-01 学生 关闭播放页后回来自动续播，换手机也能接上进度 再次打开自动 seek 到最后进度 ±5s；跨设备续播一致（进度服务端存储） P0
US-02 学生 自由倍速和切换画质 0.5x~2x 每档 0.25 即时生效；手动切画质不重置播放位置与倍速 P0
US-03 学生 边看边记带时间戳的笔记和截图 当前秒生成笔记；笔记列表点击跳转到对应时间点；截图可回看 P1
US-04 学生 搜关键词直接定位到讲这句话的视频片段 命中字幕原文 → 返回视频 + 时间点；点击进播放自动 seek P1
US-05 教师 把 4GB 的课程大视频上传到指定章节 分片上传成功；断网后继续传从缺口续；合并后 MD5 一致并自动转码 P0
US-06 教师 直播结束后自动生成回放，我剪掉前 5 分钟等待时间再发布 直播结束 ≤10 分钟生成草稿并关联原房间；裁剪后生成新文件、源文件保留 P0
US-07 教师 看到班级每个人每个视频的完播情况 班级报表：覆盖率 + 未看名单；支持 CSV 导出 P1
US-08 教师 给回放挂上字幕，让听不清的同学拖字幕学习 SRT 上传即显；AI 转写生成可校对，保存后 source 由 ai 改为 manual P1
US-09 管理员 审核教师上传的公开视频，防止不当内容外泄 待审队列可查；驳回需填原因并通知上传者；未过审视频学生端不可见 P0
US-10 管理员 掌握存储占用并控制成本 占用/课程分布/TOP10 大文件可见；配额 ≥80% 触发告警通知 P2
📐 优先级口径
P0 = M1/M2 必须交付（上传、播放、录播联动、审核）；P1 = M3/M4 智能与度量增强；P2 = 运营治理项，可后置。整体功能包优先级：P1（核心教学功能），对齐 WBS-P D-08。

05 · API Preview

§5 接口设计（~20 端点）

新增模块 /api/v1/video/*，统一前缀 /video，按子资源分组。所有端点需 Authorization: Bearer {token}。

5.1 · 视频管理（7）

GET/video/videos?course_id=&chapter_id=&tag=&status=&sort=&offset=&limit=
视频列表（学生默认仅 published + 已选课程；教师看自己课程全部）
GET/video/videos/{video_id}
视频详情（含 file 档位、我的进度、笔记数、字幕轨列表）
POST/video/videos
创建视频记录 + 返回 upload_id 分片上传凭证（teacher 课程内/admin 全局）
POST/video/videos/{video_id}/upload
分片上传/断点续传（part 序号 + MD5；complete 动作触发转码流水线）
PUT/video/videos/{video_id}
更新元信息 / 替换源文件（owner 或 admin）
DELETE/video/videos/{video_id}
软删除（status→archived，30 天恢复窗口）
POST/video/videos/{video_id}/audit
管理员审核：approve / reject（reject 带 reason → 通知上传者）

5.2 · 录播回放（4）

POST/video/recordings/from-live
直播转录播：D-01 结束事件内部调用，body {room_id, recording_url} → 创建 videos 草稿并入转码队列
POST/video/videos/{video_id}/trim
录播剪辑：入点/出点秒 + 静音区间数组 → 异步生成新文件（源保留）
POST/video/videos/{video_id}/publish
发布 / 下架（action=publish|unpublish；权限校验 + 审核状态校验）
PUT/video/videos/{video_id}/schedule
定时发布：设定 publish_at（到点由调度任务自动上架）

5.3 · 播放交互（5）

GET/video/videos/{video_id}/play
播放凭证：校验选课/密码/审核 → 返回 m3u8 地址（含时效签名）+ 续播位置
PUT/video/videos/{video_id}/progress
观看进度上报 {progress_seconds, watched_seconds, device_type}（UPSERT video_views，幂等）
GET/video/videos/{video_id}/notes
我的笔记列表（按 timestamp_seconds 排序；DELETE /video/notes/{note_id} 删除）
POST/video/videos/{video_id}/notes
创建时间戳笔记（content + timestamp_seconds，可选 screenshot_url 先传截图对象）
GETPOST/video/videos/{video_id}/transcripts?language=zh
取字幕轨（播放器渲染）；POST 上传 SRT 或触发 AI 转写（body {source:"ai", language}）

5.4 · 检索分析（4）

GET/video/search?q=&course_id=&offset=&limit=

06 · Storage & Transcoding

§6 存储与转码策略

6.1 · 存储方案（可插拔驱动）

后端定位说明
本地磁盘开发 / 演示与 Docker 卷挂载配合，默认驱动，零依赖起步
MinIO 自建校园内私有化部署S3 协议，数据不出校；docker-compose 增加 1 服务即可
阿里云 OSS / 腾讯云 COS生产 + CDN 加速生命周期规则（archived 30 天转低频/冷存），配 RAM 子账号
⚠ 驱动抽象
统一 StorageDriver 接口（put / presign_upload / presign_get / delete），file_url 存逻辑对象键而非物理地址——换后端不动数据。密钥全部环境变量注入（如 STORAGE_BACKEND / OSS_ENDPOINT）。

6.2 · 转码流水线

1
分片合并 + 校验
MD5 校验 → 源文件落对象存储（is_original）→ 状态 processing
2
FFmpeg 多码率转码
1080p(4M)/720p(2M)/360p(800k) H.264+AAC，任务队列（Redis）串行 worker 防打满 CPU；4K 源仅保留降采样档位
3
封面 + 雪碧图
默认抽第 60s 帧；按 10s/格生成进度条预览雪碧图
4
关键帧提取（AI）
PPT 切换点 / 板书变化检测 → keyframes 产物（模块 D）
5
语音转写（ASR）
讯飞/通义听悟 → video_transcripts(source=ai, format=json)
6
HLS 切片 + 入库就绪
m3u8/ts 分片 → 通知上传者：可审核/可发布；任一步失败可重跑且不产生脏产物

6.3 · CDN 分发

  • 热点视频（高峰并发）边缘缓存 m3u8 + ts 分片；回源走对象存储内网
  • 播放凭证带时效签名（默认 2h），防盗链；无 CDN 环境回退 Nginx /media 同源反代（复用 D-01 已验证链路）

6.4 · 存储成本预估

参数估算
单位体积1 小时 1080p ≈ 1.5 GB（4 Mbps 码率）
内容规模100 门课 × 15 周 × 2 小时/周 = 3000 小时
多码率冗余1080p + 720p + 360p + 源保留 ≈ 2.0~2.2×
总占用裸体积 4.5 TB × 冗余 ≈ 6 TB（学期峰值），归档清理后稳态约 4~5 TB
成本参考OSS 标准存储 ≈ ¥0.12/GB/月 → 6 TB ≈ ¥740/月；MinIO 自建按磁盘一次性投入 + 运维

  • R1 · 直播平台未定（继承 D-01 未决项）：mock:// 占位链路无真实录制产物，from-live 需按「录制文件可访问」假设先行，接口留适配层；上线前必须锁定云厂商并验证录制导出格式
