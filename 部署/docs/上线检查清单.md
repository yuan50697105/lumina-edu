## 🚨 回滚方案

```bash
# 1. 紧急停服
cd 部署 && docker compose down

# 2. 数据库回滚（保留最近备份）
cp backups/lumina_backup_<latest>.sql.gz backups/emergency_before_rollback.gz
gunzip < backups/lumina_backup_<latest>.sql.gz | mysql -u "$DB_USER" -p"$MYSQL_PASSWORD" "$DB_NAME"

# 3. 切回旧版本镜像
git checkout <last_good_commit> -- 部署
docker compose up -d

# 4. 通知业务方
```
